AI Customer Support Agent

Auto-handles routine airline support messages, escalates risky ones to a human, and tests every change before it ships.

1. Try the agent

Type a customer message. The agent predicts the intent, finds similar past cases and decides whether a human is needed.

2. Improvement loop

Each proposed change is re-run on all 200 test messages and gets one verdict. A change is blocked if it breaks a guardrail.
