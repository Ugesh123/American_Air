# AmericanAir AI Support Agent — Hiver SDE Take-Home

Real, evaluated, and honestly-limited implementation. See `REPORT.md` for the
full writeup, `DECISIONS.md` for the engineering decision log, and
`GOLDEN_SET.md` for the evaluation-set methodology.

## What actually ran, and what didn't

Everything below **except reply generation and LLM judging** was executed in
the development environment and produced the real numbers in `results/` and
`REPORT.md`. Generation and judging require an LLM API key and internet
access that the development sandbox didn't have — the code is complete and
ready to run, but has never actually been executed. Follow §5-6 below to run
them yourself; nothing in this repo claims otherwise.

## 1. Setup

```bash
pip install -r requirements.txt
```

No GPU, no Docker, no external services required for steps 2-4 below.

## 2. Reproduce the dataset (optional — already-built output is included)

```bash
python3 src/preprocessing/build_dataset.py --input /path/to/twcs.csv --output_dir data/processed
```
Produces `data/processed/{train,dev,eval_pool}.jsonl` and `data/step2_stats.json`.
Deterministic (chronological split, no randomness). ~18 seconds on a laptop.

## 3. Reproduce the golden-set candidate pool (optional — already-built)

```bash
python3 src/preprocessing/sample_golden_set.py \
    --eval_pool data/processed/eval_pool.jsonl \
    --train data/processed/train.jsonl \
    --output data/golden_set/candidates_200.jsonl
```
Deterministic (seed=42). The 200 `gold_*` labels themselves
(`data/golden_set/labels.json`) are real human annotations and are not
regenerated by this script.

## 4. Run baselines, train the classifier, run the full pipeline, compute metrics

```bash
python3 baselines/trivial_baseline.py
python3 baselines/simple_ml_baseline.py
python3 src/intent/train_classifier.py
python3 src/pipeline.py --golden_set
python3 evaluation/metrics/intent_metrics.py
python3 evaluation/metrics/escalation_metrics.py
python3 evaluation/metrics/retrieval_metrics.py
python3 evaluation/metrics/headline_metric.py
```
Each writes its output to `results/`. This is the exact sequence that produced
every number in `REPORT.md`. Total runtime: well under 2 minutes on a laptop.

Try a single message through the live pipeline:
```bash
python3 src/pipeline.py --text "my flight got delayed and nobody told me anything"
```

## 5. Run reply generation (requires your own API key + internet)

```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-...        # Windows (cmd): set ANTHROPIC_API_KEY=sk-...
python3 src/generation/generate_replies.py
```
Produces `results/generated_replies.jsonl` (200 grounded replies).

## 6. Run the LLM judge, then the human-agreement study (requires your own API key)

```bash
python3 evaluation/judge/run_judge.py          # produces results/judge_scores.jsonl
python3 tools/judge_agreement_tool.py          # open http://localhost:8421, score 60 replies yourself
python3 evaluation/metrics/judge_agreement.py  # produces results/judge_agreement_metrics.json
```

## 7. Run the tests

```bash
python3 -m unittest discover tests -v
```
19 tests: text-cleaning regression tests, escalation-policy unit tests, data-integrity
checks (leakage, golden-set schema), and a pipeline smoke test. All pass.

## 8. To relabel or extend the golden set

```bash
python3 tools/label_tool.py
```
Then open `http://localhost:8420`.

## Repository structure

```
data/processed/            cleaned, split train/dev/eval_pool
data/golden_set/           candidates_200.jsonl + labels.json (200 real human labels)
src/preprocessing/         Step 2 pipeline (build_dataset.py) + cleaning + golden-set sampler
src/intent/                weak-supervision keywords + classifier training
src/retrieval/             TF-IDF retriever (active) + embedding retriever (documented, untested here)
src/escalation/            deterministic AUTO_HANDLE/ESCALATE policy
src/generation/            LLM reply generation (coded, not executed here)
src/pipeline.py            end-to-end agent
baselines/                 trivial + simple-ML baselines
evaluation/metrics/        intent / escalation / retrieval / judge-agreement metrics
evaluation/judge/          LLM-as-judge (coded, not executed here)
tools/                     local labeling tool + judge-agreement tool (stdlib only, zero deps)
results/                   every real computed metric + model artifacts
tests/                     unittest suite
REPORT.md, DECISIONS.md, GOLDEN_SET.md, README.md (this file)
```
